# 速報ハブ

電車遅延・渋滞情報・地震/災害・天気をジャンルごとに選び、路線や地域まで絞り込んで一元的に確認できるアプリ。すべて無料のデータソースのみで構成しています。

## 開発

```bash
npm install
npm run dev
```

http://localhost:3000 を開く（`.claude/launch.json` 経由でBrowserプレビューを使う場合はポート3100）。

## データソース

| ジャンル | ソース | 登録 |
|---|---|---|
| 天気 | [気象庁 天気予報API](https://www.jma.go.jp/bosai/forecast/)(天気・気温・降水確率)、[Open-Meteo](https://open-meteo.com/)(降水量の予測) | 不要 |
| 地震・災害 | [P2P地震情報API](https://www.p2pquake.net/) | 不要 |
| 電車遅延 | [ODPT(公共交通オープンデータセンター)](https://developer.odpt.org/) | **要登録**(無料。東京メトロに必要) |
| 渋滞情報 | [JARTICオープンデータ](https://www.jartic-open-traffic.org/) | 不要 |

渋滞情報は現在サンプルデータを表示しています。

### 電車遅延（ODPT）

電車遅延の画面は路線を選ぶのではなく、いま運行情報（遅延・運休・お知らせ等）が出ている路線を全事業者から集めて重大度順に表示します。エリア（首都圏 / 北関東・甲信越 / 東北 / その他）と事業者での絞り込み、「更新」ボタンがあり、初期表示は首都圏です。

ここでの「首都圏」は一般的な狭義の意味の1都3県（東京都・神奈川県・埼玉県・千葉県）です。法律上の首都圏（首都圏整備法の1都7県）は茨城・栃木・群馬・山梨を含みますが、含めていません。路線は「主な区間が1都3県内にあるか」で分けています。

- 東京メトロ・都営・東急・京王・西武は全路線が首都圏です。
- JR東日本は `train.ts` の `JR_EAST_METRO_LINES` などの表で分けます（表にない路線は東北扱い）。鹿島線（茨城）、伊東線（静岡）、中央本線（主に山梨・長野）は首都圏に含めません。
- 東武は、鬼怒川線・伊勢崎線・桐生線・小泉線・日光線・佐野線・宇都宮線を北関東として `TOBU_OUTSIDE_METRO_LINES` で分けます。
- 宇都宮線・高崎線・八高線・久留里線のように一部区間が1都3県外にある路線は、首都圏側の主な区間で判断して首都圏に入れています。東武のように多数の路線に全く同じ文面が出ている場合は1件にまとめます。

| 事業者 | 取得 |
|---|---|
| 東京メトロ | 実データ（`ODPT_CONSUMER_KEY` が必要） |
| 都営地下鉄 | 実データ（トークン未設定でも公開APIで取得可） |
| JR東日本・東急・京王・西武・東武 | 「公共交通オープンデータチャレンジ」限定データ（`ODPT_CHALLENGE_KEY` が必要。下記参照） |
| 小田急・京成 | ODPTに運行情報の提供がないため対象外 |

トークンが未設定の事業者は表示されず、その旨の注意書きが画面に出ます。

設定手順（東京メトロ）:

1. https://developer.odpt.org/ で開発者登録し、アクセストークンを取得する
2. プロジェクト直下の `.env.local` に `ODPT_CONSUMER_KEY=<トークン>` と書く（Git管理外）
3. 開発サーバーを再起動する（環境変数は起動時に読み込まれる）

#### JR東日本・私鉄（チャレンジ限定データ）

通常トークンとは別の、チャレンジ専用トークン・別ホスト(`api-challenge.odpt.org`)で提供されています。

1. 開発者サイトで「公共交通オープンデータチャレンジ2026」にエントリーする（個人可。エントリー後にチャレンジ限定データへアクセスできる）
2. 発行されたチャレンジ用トークンを `.env.local` に `ODPT_CHALLENGE_KEY=<トークン>` と書き、開発サーバーを再起動する

制約（公式の記載）: 提供は「チャレンジの終了まで」（コンテスト期間は2027-03-12まで）。チャレンジ限定ライセンスの条件（アプリの公開義務など）は、エントリー時に必ず原文を確認してください。

路線名は、JR東日本以外はODPTの路線マスタ(`odpt:Railway`)から取得し、JR東日本(マスタが取得できない)は `train.ts` の `JR_EAST_NAMES` の対応表で補います。対応表にない路線は、運行情報の文面の先頭から路線名を推定します。西武は路線別ではなく「西武鉄道全線」の1件のみを返します。

対象の事業者を増やす場合は `src/lib/sources/train.ts` の `OPERATORS` に追加します。

### 天気

初期表示は神奈川県です(`src/lib/genres.ts` の `defaultValue`)。予報区ごとに3日分の天気アイコン・最高/最低気温・降水確率(6時間ごと)・降水量(予測)をカードで表示します。降水量は気象庁の予報に含まれないため、都道府県ごとの代表地点(県庁所在地付近、`src/lib/sources/weather.ts` の `AREA_COORDS`)についてOpen-Meteoの予測値を使っています。取得できない場合は降水量だけ「–」になります。

### 渋滞情報を実データにする

JARTICの交通量APIは登録不要で利用できますが、直轄国道のみで高速道路は対象外であり、路線名がなく緯度経度と観測地点IDのみで提供されるため、現在の「路線名で選ぶ」UIとは両立しません。方針が決まるまではサンプル表示のままです（詳細は `HANDOFF.md` 参照）。実装する場合は `src/lib/sources/traffic.ts` の TODO コメントを参照してください（取得できるのは交通量であり、渋滞度への変換ロジックが別途必要）。

## 構成

- `src/lib/types.ts`: ジャンル横断の正規化データ形式(`NormalizedItem`)
- `src/lib/genres.ts`: ジャンルごとの選択肢・メタ情報(単一の設定源)
- `src/lib/sources/*.ts`: ジャンルごとの外部APIアダプタ
- `src/lib/cache.ts`: 無料APIへの過剰アクセスを避けるための簡易インメモリキャッシュ
- `src/app/api/[genre]/route.ts`: フロントから叩くAPI Route
- `src/app/[genre]/page.tsx` + `src/components/GenreView.tsx`: ドリルダウン画面
